Reuse profile outcome choices and MetricPrompts. Questions cost no AI edits. Preserve typed answers on Back; allow uncertainty and no metric; confirm before losing answers. Desktop dialog and mobile bottom sheet use native dialog focus containment, Escape handling, scrollable content and pinned actions.

Files: ImpactGuide component/tests, BulletImproveMenu integration/tests, template integration tests, resume assist API and assistBullet prompt. No database changes.

Acceptance: questions make no AI call; blank metric templates cannot submit; no-number path works; answers survive Back; suggestions require explicit acceptance; desktop/mobile keyboard and touch checks; typecheck, lint, tests, production build; review diff for bugs.
